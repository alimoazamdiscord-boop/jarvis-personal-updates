# Jarvis Personal — experimental Android builds

Public APK downloads and the in-app update channel for the Persian Jarvis Personal assistant.

Use the latest release APK. Android 8+ is required. The app checks this repository's official release metadata; APK hashes, package identity and signing certificates are checked before Android's installation confirmation.

This is an experimental, debug-signed test build. Speech recognition, Bluetooth routing, supported music sources and background operation may vary by device. Do not rely on it for safety-critical tasks. No guarantee of universal song access or recognition accuracy.

Automatic downloads default to unmetered networks. Installation requires the user's Android approval. No account credentials, signing keys, personal recordings or phone logs are published here.

Third-party voice engine updates are downloaded from the original AvaCore releases, not redistributed here: https://github.com/PlayFoundryHQ/AvaCore/releases
